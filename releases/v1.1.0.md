# v1.1.0 - 2026-07-11

## Added

- CI: a local-link checker (`scripts/check-local-links.mjs`) that validates markdown link targets exist, and specifically enforces root-relative `_sidebar.md` links
- "See Also" cross-link to the companion [ScamWard](https://github.com/goAuD/ScamWard) repo

## Fixed

- Sidebar navigation 404s when moving between nested docs pages (`relativePath: true` resolved non-rooted sidebar links against the current route instead of the docs root)
- A filename containing literal parentheses (`pfsense_cpu_optimalization(low_performance_hardware).md`) that broke link parsing - renamed to drop them

## Changed

- Finished translating the last Hungarian-only docs to English (`pandoc.md`, `network_topology_diagram.md`, `windows_debian_backup_cheatsheet.md`)
- Replaced all en-dashes with plain hyphens across docs
- Removed emoji from headings and badges across `docs/` for consistency with the v1.0.0 "removed emojis" changelog entry
- Replaced the default docsify-themeable dark skin with a custom "rack unit" theme: self-hosted JetBrains Mono + IBM Plex Sans, a status-LED accent system, and a signature pulsing status dot on page headings
