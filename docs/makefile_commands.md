# Makefile Commands Reference

![Tool](https://img.shields.io/badge/tool-makefile-orange)
![License](https://img.shields.io/badge/license-MIT-blue.svg)

| Command         | What it does                            | When to use          |
| --------------- | --------------------------------------- | -------------------- |
| `make install`  | Installs scripts to executable location | once per system      |
| `make lock`     | Locks kernel version                    | when everything works |
| `make unlock`   | Unlocks version lock                    | when you want to upgrade |
| `make check`    | Checks if akmods is available           | anytime              |
| `make cleanlog` | Deletes the log file                    | for clean monitoring |
